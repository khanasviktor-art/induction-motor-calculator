# Язык интерфейса (RU / EN)

Приложение — инженерный калькулятор асинхронного двигателя (ПУЭ / IEC 60364).
Английский язык — для инженера, который привык к IEC-терминологии. Перевод должен
читаться как родной текст, а не как подстрочник.

## Как устроено

| Что | Где |
|---|---|
| переключатель RU/EN в шапке, `localStorage` (`motor-calc-lang`) | `src/index.html`, `src/app.js` (`bind`, `relang`) |
| `t()` — точная строка, `tf()` — шаблон с `{подстановками}` | `src/i18n.js` |
| `tHtml()` — перевод разметки, `translateDom()` — динамики после рендера | `src/i18n.js` |
| `nf()` — числа в локали языка (`1 469,2` / `1,469.2`) | `src/i18n.js` |
| словарь RU → EN (куски по темам) | `src/lang-en/*.js` → сборка в `src/lang-en.js` |
| подписи осей и легенды canvas | `CHART_LABELS` / `CHART_ARIA` в `src/app.js` |
| отчёт/PDF и листы XLSX | `openReport` (`translateDom` для окна отчёта), `exportXlsx` (`I18N.plain`) |
| тест | `tests/i18n.mjs` |

Ключ словаря — **русская строка** ровно в том виде, как она стоит в `src/`: поэтому
русский режим не меняет ни одного символа, а новый русский текст автоматически
становится ключом (нужен только перевод).

Числа в ключах записаны по-русски (`29,4`), а на экране в EN они уже отформатированы
`nf()` (`29.4`). Поэтому, кроме точного совпадения, `i18n.js` ищет ключ с числами,
заменёнными на `#`, и подставляет числа из исходной строки. Отсюда правило для
переводчика: **если в ключе есть числа, в переводе должно быть столько же чисел**,
иначе строка останется русской.

## Формат файла словаря

Каждый кусок — самостоятельный скрипт:

```js
/* 04-cable — кабель и защита */
window.MC_EN = Object.assign(window.MC_EN || {}, {
  "Сечение, мм²": "Cross-section, mm²",
  "Падение напряжения ≤ {v} %": "Voltage drop ≤ {v} %",
});
```

- Ключ — русская строка **байт в байт** как в `i18n-work/inv-N.json` (включая
  пробелы, `·`, `≤`, `—`, `«»`, `°C`, `₂`, `₁`, `н`).
- Значение — английский текст.
- Файл должен быть валидным JS: кавычки экранируйте, переводы берите в двойные
  кавычки, внутри — одинарные при необходимости. Многострочные переводы — `\n`.
- Один ключ — одна строка. **Ничего не удаляйте и не добавляйте ключи** сверх
  инвентаря (лишние не вредят, пропущенные — вредят: останется русский текст).

## Обязательно

1. **Подстановки `{x}` сохраняются дословно** и в том же количестве:
   `"Пик пуска {i} А; отсечка {m} А."` → `"Starting peak {i} A; instantaneous trip {m} A."`
   Порядок слов можно менять, имя подстановки — нет.
2. **Числа и единицы уже отформатированы** до подстановки (локаль en: `11.47`).
   Не добавляйте свои единицы внутрь подстановки.
3. **Не переводите**: `DOL`, `Y–Δ`, `VFD`, `Soft`, `MCCB`, `MCB`, `XLPE`, `PSC`,
   `IEC`, `ABB`, `IEK`, `CHINT`, `Tmax XT`, `S200`, `BA47`, типоразмеры (`АИР160S4`),
   обозначения формул (`P₁`, `P₂`, `M`, `s`, `n`, `cosφ`, `η`, `ΔU`, `I²t`, `U`, `I`, `f`).
4. Обозначения величин: `Iн` → `Iₙ`, `Mн` → `Mₙ`, `Mп` → `Mst`, `Mmax` → `Mmax`,
   `sкр` → `scr`, `n₁` → `n₁`, `f₂` → `f₂`, `Uф` → `Uph`, `Iп` → `Ist`, `Sп` → `Sst`,
   `ΔUп` → `ΔUst`, `J∑` → `JΣ`, `τ` → `τ`, `Iдоп` → `Iadm`, `Iн.авт` → `Iₙ.brk`.
   В тексте «номинальный ток Iн» → «rated current Iₙ».
5. Единицы: `В`→`V`, `А`→`A`, `кВт`→`kW`, `Вт`→`W`, `кВ·А`→`kVA`, `квар`→`kvar`,
   `Гц`→`Hz`, `об/мин`→`rpm`, `Н·м`→`N·m`, `кг·м²`→`kg·m²`, `мм²`→`mm²`, `мм`→`mm`,
   `м`→`m`, `км`→`km`, `кА`→`kA`, `мА`→`mA`, `Ом`→`Ω`, `мин`→`min`, `ч`→`h`, `с`→`s`,
   `°C`→`°C`, `шт`→`pcs`, `дв`→`motors`, `/ч`→`/h`, `Ед.`→`Unit`.
6. Русская типографика → английская: `«текст»` → `"text"` (или без кавычек),
   десятичная запятая в тексте → точка. Тире `—` можно оставить.

## Проверка перед сдачей

```bash
node tools/i18n-check.cjs src/lang-en/NN-имя.js i18n-work/inv-N.json
```

Должно быть `не переведено: 0` и без предупреждений о подстановках.
