# Инструкции для AI-агентов

Этот файл — краткий контракт для агентов, которые продолжают разработку. Сначала прочитайте:

1. `README.md`
2. `docs/ARCHITECTURE.md`
3. `docs/MODEL.md`
4. `docs/LIMITATIONS.md`
5. `docs/TESTING.md`
6. `docs/DEVELOPMENT.md`

## 1. Инварианты

- Приложение — **один офлайн-файл** `index.html`. Никаких CDN, внешних шрифтов, сетевых запросов, runtime-зависимостей.
- Исходники — `src/`. `index.html` — сгенерированный; **не редактируйте его вручную**.
- Сборка: `npm run build` → `index.html`.
- Тесты: `npm test` (сборка + Playwright).
- Сохраняйте кредит: «Сделано с помощью DeepSeek · Виктор Ханас · khanas.viktor@gmail.com».
- Не ломайте `file://`, мобильный вид, светлую/тёмную тему, офлайн.
- Не удаляйте `?debug=1` — на нём держатся тесты.
- **Язык.** Весь видимый текст проходит через i18n: статическая разметка переводится автоматически, динамическая — `t()`/`tf()`/`tHtml()` или обходом `translateDom()` после рендера. Новый текст в `src/` = новый ключ словаря (ключ — сама русская строка), перевод — в `src/lang-en/*.js`, затем `node tools/i18n-assemble.cjs`. Подстановки `{x}` не переименовывать. Проверка — `tests/i18n.mjs`.

## 5. Ловушки

1. **`build.mjs` и `$$`.** Замена должна быть функцией `() => …`; иначе `$$` в JS станет `$` и приложение упадёт с `Identifier '$' has already been declared`.
2. **Скрытая вкладка.** У canvas `clientWidth = 0`; для отчёта `resize()` подставляет 640×260. Не убирайте fallback.
3. **Данные графиков.** Тесты сверяют `chart.series` с `rep.sweep`/`op`; если меняете шкалы/серии — обновите тесты и `docs/ARCHITECTURE.md`.
4. **cosφ.** На графике — на зажимах (`cosT`), не по номинальному U. Не возвращайте старую формулу `p1/(√3·Uном·I)`.
5. **Момент.** Кривая M(n) — при `uOp = op.U/m.U`; Mmax в таблице — при номинальном U. Не «исправляйте» это без обновления подписи и тестов.
6. **0 % нагрузки.** `P₂ = 0`, `η = 0`; не возвращайте минимальное скольжение в P₂.
7. **Софтстартер.** `uSoft` хранит **командное** напряжение (до падения в кабеле); ограничение тока stateful. Не заменяйте на одношаговую формулу — ток снова начнёт превышать уставку.
8. **«Не разгоняется».** Флаг `stalled` ставится после 3 с устойчивого стояния и снимается при `n > 5 %`; статус таблицы — по `tStart`. Не возвращайте старую логику с `t > 0.5`.
9. **Однофазные.** Каталог скрыт; `loaded = 2`; автомат 1P; Y–Δ/AT отключены; конденсатор не подбирается. Не включайте каталог АИР для 1 фазы.
10. **Подсказки.** Все поля с `TIPS[id]` получают иконку; отдельного `TIP_FIELDS` нет. Не добавляйте иконку внутрь `<label class="checkline">` (клик переключит чекбокс).
11. **Тур.** Автозапуск через 1,2 с; ключ `motor-tour-v1`; тесты выставляют ключ, иначе тур блокирует клики.
12. **XLSX.** ZIP без сжатия; строки `inlineStr`; не добавляйте внешнюю библиотеку.
13. **Отчёт.** Новое окно с inline CSS; 5 PNG; `window.print()`. Не заменяйте на сервер.
14. **Тесты.** `CHROME_PATH`; в CI — `browser-actions/setup-chrome`. Глубокий прогон — `tests/deep.mjs`: при правке расчёта/порогов обновите эталоны `node tests/deep.mjs --baseline` **осознанно** и посмотрите diff. Упакованное приложение проверяется `tests/desktop.mjs` (нужен `APP_EXE`, см. `docs/WINDOWS.md`).
15. **i18n.** `nf()` живёт в `i18n.js` (локаль языка) — не возвращайте `toFixed`/`toLocaleString('ru-RU')` в форматирование ради «привычной запятой»: в EN нужна точка. `const t = …` как локальная переменная затеняет переводчик — не называйте так переменные в `app.js`.

## 6. Рабочий процесс

1. Прочитайте `docs/MODEL.md`/`LIMITATIONS.md` по теме.
2. Внесите изменения в `src/`.
3. `npm run build`.
4. `npm test` (или профильный тест).
5. Проверьте визуально (`index.html`, светлая/тёмная, мобильный).
6. Обновите:
   - `docs/MODEL.md` — если формулы/допущения;
   - `docs/LIMITATIONS.md` — если появилось ограничение;
   - `docs/TESTING.md` — если эталоны;
   - `docs/DATA.md` — если данные;
   - `CHANGELOG.md`;
   - `docs/screenshots/` — если UI.
7. Закоммитьте `src/`, `index.html`, docs, tests.

## 7. Definition of done

- [ ] `npm run build` проходит.
- [ ] `npm test` зелёный.
- [ ] `index.html` закоммичен.
- [ ] Нет ошибок в консоли.
- [ ] 1 фаза и 3 фазы не сломаны.
- [ ] Светлая/тёмная тема.
- [ ] Мобильный вид.
- [ ] Документация/чейнджлог обновлены.
- [ ] Кредит сохранён.

## 8. Чего не делать

- Не добавлять jQuery/React/Chart.js/CDN.
- Не переносить расчёты в Web Worker без необходимости.
- Не менять округления в UI без причины.
- Не «улучшать» физику без тестов и документации.
- Не удалять предупреждения о том, что это инженерная оценка.
- Не коммитить `node_modules`, `test-results`, `.DS_Store`.

## 9. Если что-то не сходится

Сначала проверьте:

- `__mcDebug.rep` — что реально посчитано;
- `chart.series` — что реально нарисовано;
- `docs/MODEL.md` — какая формула заложена;
- `docs/LIMITATIONS.md` — не является ли это известным упрощением.

Если расхождение — это баг, добавьте тест, который его ловит, и только потом исправляйте.
