# Windows-версия: что должно работать и как это проверить

Приложение — один офлайн-файл `index.html`. Windows-обёртка нужна, чтобы получить
своё окно без браузерной обвязки, но **сохранить весь текущий функционал**.
Этот документ — два инструмента: автотест упакованного приложения и приёмочный
чек-лист.

## 0. Состояние на сегодня

Собрана оболочка на Electron (`desktop/`): portable exe
`desktop/dist/MotorCalculator-0.9.0-win-x64.exe` (71 МБ), 24 автоматические
проверки проходят, включая реальное сохранение CSV, XLSX, PNG и PDF в папку.

```bash
npm run desktop          # запустить окно без сборки exe
npm run desktop:dist     # собрать portable exe
APP_EXE="desktop\dist\MotorCalculator-0.9.0-win-x64.exe" npm run test:desktop
```

Сделано в оболочке: окно с запоминанием размера и позиции, меню
(Файл/Правка/Вид/Справка), PDF отчёта через `printToPDF`, сохранение
CSV/XLSX/PNG/проекта через системные диалоги, перехват прочих скачиваний,
открытие ссылок в браузере, single-instance, «О программе» с двумя версиями.

Осталось проверить руками: системные диалоги сохранения и печать на бумаге
(их нельзя автоматизировать), поведение на 1024×600 и при масштабе 125–200 %,
запуск на чистой машине без сети.

## 2. Подводные камни обёртки (проверить обязательно)

1. **Печать и PDF.** `window.print()` во встроенном браузере может открыть
   непечатаемое окно. Правильное решение — печать через движок обёртки
   (`PrintToPDF` у WebView2 / `webContents.printToPDF` у Electron) с сохранением
   файла через диалог. Отчёт открывается через `window.open` — обёртка должна
   разрешать новые окна (`NewWindowRequested`), иначе кнопка «Печать / PDF»
   ничего не покажет.
2. **Скачивания.** CSV/XLSX/PNG создаются как `Blob` + `<a download>`. В WebView2
   нужно обработать `DownloadStarting` и спросить папку; иначе файл молча не
   появится. Проверка: каждый из трёх экспортов реально создаёт файл.
3. **`localStorage` и origin.** Состояние, варианты и язык лежат в `localStorage`.
   Если обёртка показывает файл как `file://`, а следующая версия — как
   `https://app.local/`, данные пользователя «пропадут». Зафиксируйте один способ
   (`SetVirtualHostNameToFolderMapping` + `https://app.local/` надёжнее: работает
   кэш, нет ограничений file-origin) и не меняйте его между версиями.
4. **Размер и запоминание окна.** Проверьте, что окно запоминает размер и
   положение и что интерфейс не ломается на 1024×600 (маленький нетбук) и при
   масштабе Windows 125–200 %.
5. **Тема.** `html[data-theme]` управляется приложением; «как в системе» —
   через `prefers-color-scheme`. Проверьте переключение темы Windows при
   открытом приложении.
6. **WebView2 runtime.** Есть в Windows 10 1809+ и Windows 11. Для чистых
   машин/LTSC нужен установщик WebView2 (Evergreen Bootstrapper). Electron
   этого не требует, но весит на порядок больше.
7. **Подпись.** Неподписанный `.exe` SmartScreen блокирует при первом запуске.
   Для личного использования — «Подробнее → Выполнить всё равно»; для раздачи —
   подпись кода.
8. **Антивирус и офлайн.** Никаких сетевых запросов приложение не делает —
   проверьте запуск с выключенной сетью (и что шрифты не тянутся из интернета:
   в приложении только системные).
9. **Иконка, версия, «О программе».** Версия в приложении (`v0.8.0`) должна
   совпадать с версией exe.
10. **Горячие клавиши.** Space (пауза моделирования), Esc (закрыть тур/подсказку),
    Ctrl+P (печать) — если обёртка перехватывает их, задокументируйте замену.

## 3. Автотест упакованного приложения

```bash
# порт отладки обёртка должна принимать так:
#   WebView2: WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222
#   Electron: --remote-debugging-port=9222
APP_EXE="C:\dist\MotorCalculator.exe" npm run test:desktop
```

Что проверяет (16 проверок): процесс поднял отладочный порт, окно с приложением
открыто, страница загружена из локального источника, приложение
инициализировано (`MC.engine`), отрисованы KPI и 9 canvas, заголовок окна,
`localStorage` работает, размер окна разумный, изменение мощности вызывает
пересчёт, подсказки открываются, темы и язык переключаются, ошибок в консоли
нет. Скриншот окна сохраняется в `test-results/desktop-window.png`.

Без `APP_EXE` шаг печатает `SKIP` и не валит `npm test`.

Дополнительно можно открыть приложение в чужом окне (отладка обёртки):

```bash
APP_EXE="C:\Program Files\Google\Chrome\Application\chrome.exe" \
APP_ARGS="--headless=new --user-data-dir=%TEMP%\mc-test" \
APP_START_URL="file:///C:/dist/index.html" npm run test:desktop
```

## 4. Приёмочный чек-лист (руками, на собранном exe)

Отметьте каждый пункт. «ОК» — если поведение совпадает с веб-версией.

**Запуск**
1. Двойной клик по exe → окно открывается без браузерной панели, заголовок
   «Асинхронный двигатель — инженерный расчёт», иконка в панели задач.
2. Интернет выключен → приложение работает так же.
3. Закрыть и открыть заново → все параметры и результаты те же.
4. Окно: свернуть/развернуть/перетащить, закрыть; размер и позиция запомнились.

**Расчёт**
5. Режим «База»: 4 полюса, типоразмер АИР160S4 → Iн ≈ 29,4 А, КПД 89 %, cosφ 0,87.
6. Переключить на 1 фазу → каталог недоступен, 2 жилы, автомат 1P, предупреждение
   о редком случае при > 7,5 кВт.
7. Ввести P₂ = 0 → расчёт не падает, значения не NaN.
8. Ползунок нагрузки 0 / 75 / 150 % → KPI и графики меняются, при 0 % η = 0.
9. «Дополнительные параметры» → горячий пуск, класс 20, пусков/час 30 → меняются
   температура и подпись теплового режима.

**Пуск**
10. Вкладка «Пуск» → «Пуск» → графики n/I/M/U/f рисуются, стадия меняется
    (ожидание → разгон → работа), «Пауза»/«Продолжить» работают, «Сброс» очищает.
11. «Наложить способ» = ПЧ → на графиках пунктир второго способа.
12. Способ пуска «Звезда — треугольник» → появляются поля времени переключения.

**Кабель и защита**
13. Длина 300 м → сечение увеличивается, в таблице выделена выбранная строка.
14. «Параллельных кабелей» 2 → I на кабель и суммарный ток пересчитываются.
15. Норматив ПУЭ → IEC: таблица токов меняется.
16. MCCB → появляется уставка отсечки; «Вышестоящий» 250 А → селективность.
17. ВТХ: график, таблица «Данные ВТХ» раскрывается, кривая и точка пуска видны.

**Экспорт и отчёт**
18. «CSV ↓» → файл сохранён (там, где ожидается), открывается в Excel.
19. «XLSX ↓» → 7 листов, числа числами, без «NaN».
20. «Скачать PNG» у графика → PNG с прозрачным/белым фоном, размер ок.
21. «Печать / PDF» → окно отчёта с 5 графиками и таблицами; печать или
    сохранение в PDF даёт читаемый документ (не пустые страницы).
22. В отчёте указаны те же числа, что на экране.

**Файлы и ссылки**
23. «Сохранить проект» → JSON; изменить параметры → «Открыть проект» → значения
    вернулись, расчёт совпал.
24. Открыть заведомо битый JSON → сообщение «ошибка файла проекта», приложение живо.
25. «Поделиться расчётом» → ссылка скопирована; открыть её в браузере → то же
    состояние, параметр `p` из адреса исчезает.
26. «+ вариант» 5 раз → в таблице 4 варианта, удаление работает, после
    перезапуска варианты на месте.

**Интерфейс**
27. Темы: светлая/тёмная/авто; при «авто» смена темы Windows меняет оформление.
28. RU/EN: переключение меняет весь текст, включая отчёт и XLSX; возврат на RU
    ничего не оставляет на английском.
29. Тур: кнопка «?» → 8 шагов, «Пропустить»/Esc закрывают, после перезапуска
    тур не навязывается.
30. Подсказки: наведение на «i» показывает текст с формулой; у края окна попап
    не выходит за экран.
31. Графики: колесо — зум, перетаскивание — сдвиг, двойной клик — сброс.
32. Мобильная раскладка не нужна, но проверьте окно 1024×600: ничего не
    обрезано, панель параметров доступна.
33. Масштаб Windows 150 % → текст не разъезжается, canvas чёткий.
34. Клавиатура: Tab обходит поля, Space на «Пуск» ставит паузу, Esc закрывает.

**Стабильность**
35. 20 переключений вкладок и 20 изменений мощности → нет ошибок, память не растёт
    бесконечно (диспетчер задач: рабочий набор стабилен).
36. Оставить приложение на 10 минут → состояние не «плывёт», таймеры не крутят
    процессор вхолостую.

## 5. Что считается приёмкой

- `npm test` зелёный (включая `deep.mjs`), `npm run test:desktop` — `ok` на
  собранном exe.
- Все пункты чек-листа отмечены «ОК»; расхождения записаны в issue с шагами.
- Версия exe = версия приложения (`v0.8.0` совпадает в подвале и в свойствах файла).
