# Инженерная модель

Документ описывает, **как считает** приложение, какие формулы и допущения используются, и где модель сознательно упрощена. Код: `src/engine.js` (установившийся режим), `src/sim.js` (переходные процессы), `src/data.js` (справочники).

Обозначения:

| Символ | Смысл |
|---|---|
| `P₂` | мощность на валу, кВт |
| `P₁` | потребляемая мощность, кВт |
| `U` | линейное напряжение сети, В |
| `Uф` | фазное напряжение обмотки, В |
| `I` | ток статора, А |
| `n`, `n₁` | номинальная и синхронная скорость, об/мин |
| `s` | скольжение |
| `M` | момент, Н·м |
| `η` | КПД, % |
| `cosφ` | коэффициент мощности |
| `J` | момент инерции, кг·м² |
| `kst` | `Iп / Iн` |
| `mst` | `Mп / Mн` |
| `mmax` | `Mmax / Mн` |

## 1. Базовые соотношения

```
n₁ = 120 · f / p
sн = (n₁ − n) / n₁
Mн = 9550 · P₂ / n
P₁ = P₂ / η
I = P₁ / (√3 · U · cosφ)        — 3 фазы
I = P₁ / (U · cosφ)             — 1 фаза
S = √3 · U · I                  — 3 фазы
S = U · I                       — 1 фаза
Q = √(S² − P₁²)
```

В программе `I` считается по фактическому напряжению на зажимах двигателя (с учётом падения в кабеле), а не только по номинальному. Поэтому при 100 % нагрузки ток может быть на 1–2 % выше `Iн`, а `cosφ` на графике — это `cosφ` на зажимах, а не на шинах.

## 2. Механическая характеристика

Используется формула Клосса плюс добавка на пусковой момент:

```
Mк(s) = 2 · Mmax / (s/sкр + sкр/s)
M(s)  = Mк(s) + boost · s³
```

- `sкр` подбирается из `sн` и `mmax`:
  ```
  sкр = sн · (mmax + √(mmax² − 1))
  ```
- `boost` подбирается так, чтобы при `s = 1` получить `Mп`:
  ```
  Mк(1) = 2 · Mmax / (1/sкр + sкр)
  boost = max(Mп − Mк(1), 0)
  ```
- Реальный максимум `MmaxReal` ищется численно (`peakTorque`), потому что добавка `boost·s³` немного смещает точку максимума.

Момент зависит от напряжения:

```
M(s, u) = M(s, 1) · u²
```

где `u = Uфакт / Uном`.

Это **не** полная схема замещения: не учитываются насыщение, вытеснение тока в стали, добавочные потери и т.п.

## 3. Ток статора

Ток раскладывается на намагничивающую и роторную составляющие:

```
i0rel = I0 / Iн
I2 = Iн · √(1 − i0rel²)
I(s) = √(I0² + I2² · T(s)/Tн · rr(s))
```

- `T(s)` — момент по формуле Клосса.
- `rr(s) = 1 + (rr1 − 1)·s²` — упрощённое вытеснение тока в роторе.
- `rr1` подбирается из условия `I(1) = kst · Iн`:
  ```
  rr1 = kst · (1 − i0rel²) / (kst² · sн)
  ```
  с ограничением `1,05…6`.
- `i0rel`:
  - 3 фазы: `0,40 − 0,045·ln(P₂) + поправка на полюса`;
  - 1 фаза: зависит от типа (конденсаторный/расщеплённая фаза/PSC), обычно `0,36…0,58`.

Ток также масштабируется по напряжению через `u` в модели момента.

## 4. Рабочая точка

`operatingPoint(motor, load, cable, U)`:

1. Задаётся начальное `uF = 1`.
2. Численно решается `M(s, uF) = Mнагр(n)` (метод дихотомии/итераций).
3. По току считается падение напряжения в кабеле, уточняется `uF`.
4. Цикл повторяется 4 раза.
5. Считаются `P₁`, `P₂`, `S`, `Q`, `η`, `cosφ`, `f₂`, температура, время до предела.

Нагрузка задаётся типом:

| Тип | Момент |
|---|---|
| `quadratic` | `M = Mн · (n/nн)²` (вентилятор) |
| `constant` | `M = const` |
| `linear` | `M ∝ n` |
| `constpower` | `P = const`, `M = P/ω ∝ 1/n`; в коде ниже 12 % скорости ограничено `8·Mн` |
| `custom` | кусочно-линейная кривая `%n:%M`, масштабируется ползунком нагрузки |

Плюс пусковой «рывок» `breakaway = 1,15` для механизмов с троганием.

`loadSweep` повторяет расчёт для 0…150 % с шагом 1 % — это данные графиков.

## 5. Кабель

```
ΔU = √3 · I · (R·cosφ + X·sinφ)     — 3 фазы
ΔU = 2 · I · (R·cosφ + X·sinφ)      — 1 фаза
R = ρ·L/S
X ≈ 0,08 Ом/км
```

- `ρ` зависит от материала и температуры жилы.
- Поправки: температура, группировка, способ прокладки, изоляция, параллельные кабели, число нагруженных жил.
- Сечение перебирается из ряда `1,5…240 мм²`.
- Критерии:
  - `Iдоп ≥ max(Iраб, Iн.авт)`;
  - `ΔUраб ≤ ΔUдоп` (по умолчанию 5 %);
  - `ΔUпуск ≤ ΔUпуск.доп` (по умолчанию 15 %).
- Если по нагреву проходит меньшее сечение, но не проходит по ΔU, сечение увеличивается; это отмечается в предупреждениях.
- Для 1 фазы — 2 нагруженные жилы; для 3 фаз — 3.

## 6. Защита

- Номинал автомата: `Iн.авт ≥ 1,25·Iраб` (для MCB — ближайший из ряда).
- Отсечка: `Iотс > 1,1·Iпуск`; для MCCB — уставка `mag × Iн`.
- `Icu` — справочное.
- Селективность: `Iверх / Iниз ≥ 1,6` (грубая оценка).
- Тепловое реле: диапазон, уставка `Iраб`.
- Контактор: `I ≥ Iраб`, `P ≥ P₂` (AC-3).
- Предохранитель aM: по пусковому току.
- УЗО: рекомендация по типу A/B и току утечки.

Это не проверка по время-токовым кривым производителя (см. `docs/LIMITATIONS.md`).

## 7. Тепловая модель

```
Tуст = Tсреды + ΔTном · (I/Iн)²
T(t) = Tсреды + (Tуст − Tсреды) · (1 − e^(−t/τ))
```

- `ΔTном` и предел зависят от класса изоляции (B/F/H).
- `τ` — постоянная нагрева (оценка по мощности или вручную).
- Время до предела:
  ```
  t = −τ · ln((Tуст − Tпред) / (Tуст − Tсреды))
  ```
  если `Tуст > Tпред`.

## 8. Переходные процессы

Уравнение движения:

```
J · dω/dt = Mэм(s, u) − Mнагр(n)
s = (ω₁ − ω) / ω₁
```

- `J = Jдвиг + Jнагрузки` (приведённый к валу).
- `Mэм` — по модели Клосса с учётом напряжения.
- `Mнагр` — по типу нагрузки.
- Интегрирование — явное, шаг 0,5 мс (live) / 1 мс (предрасчёт).
- Тепловая модель интегрируется параллельно (упрощённо).

Способы пуска:

| Способ | Напряжение/частота |
|---|---|
| DOL | `U = Uном` |
| Y–Δ | `1/√3` до `tSwitch`, затем полное; короткий провал 0,06 с |
| Автотрансформатор | `0,65·Uном` до `tSwitch`, затем полное |
| Софтстартер | рампа от `uStart` до 100 % за `tRamp`; ограничение тока |
| ПЧ | рампа `f` от 0 до `fном`; `U/f = const`; замкнутый контур по скорости |

Ограничение тока софтстартера:

```
k = min(kRamp, kPrev + rate·dt)
если I > Iогр: k = max(k0, kPrev · Iогр / I)
```

- `k` — командное напряжение (до падения в кабеле).
- Если `Iогр` слишком мало для нагрузки, двигатель честно не разгоняется; это не ошибка модели, а физическое ограничение.

Флаг «опрокидывание»:

- двигатель стоит (`n < 2 % nн`) и момент ниже нагрузки;
- условие держится **3 с**;
- при `n > 5 % nн` флаг снимается;
- статус «разгон» в таблице определяется по фактическому `tStart` (достижение 95 % nн), а не по флагу.

## 9. Типовые данные

- Трёхфазные: `src/data.js`, `MOTOR_DB`, 54 записи; крупные — `typical: true`.
- Однофазные: `TYPICAL_1PH` в `src/engine.js`, три типа:
  - `capacitor` — конденсаторный;
  - `split` — с расщеплённой фазой;
  - `psc` — постоянный конденсатор.
- Интерполяция — логарифмическая по мощности, с ограничением на краях.
- Однофазные данные — **типовые**, не каталог; конденсатор не подбирается.
- **Соединение обмоток**: для каталожного двигателя схема Y/Δ выбирается автоматически. При ручном неверном соединении вводится коэффициент `uф/Uном`; момент масштабируется как квадрат, ток — по модели. Для 380/660 при 380 В нужна Δ; Y даёт 220 В на фазе и ~1/3 момента.
- **Постоянная мощность** при нулевой скорости — сингулярность; пуск без разгрузки/сцепления невозможен. Программа честно показывает «не разгоняется».
- Типовые однофазные кривые — до 7,5 кВт. Выше 7,5 кВт используется последняя точка, приложение выдаёт предупреждение; это оценка, а не паспорт.
- «Число полюсов» — это скорость (`n₁ = 120·f/p`), а не количество обмоток. У однофазного есть главная и пусковая/вспомогательная обмотка; тип (`capacitor`/`split`/`psc`) задаёт схему пуска.

## 10. Что проверено

Автотесты (`tests/charts-static.mjs`, `tests/charts-transient.mjs`) проверяют:

- совпадение данных графиков с расчётным массивом;
- рабочую точку на кривой момента и на линии нагрузки;
- `I`, `cosφ`, `η`, `P₂` при 100 % в пределах допусков от паспорта;
- монотонность `I`, `U`, `n`, `s`, `P₁`, `P₂`;
- `η(0) = 0`, `P₂(0) = 0`;
- стартовый/максимальный момент;
- `tStart`, пиковый ток/момент в live-симуляции и в таблице сравнения;
- методы пуска и наложение;
- однофазные и трёхфазные ограничения.

Эталонные значения — в `docs/TESTING.md`.

## 11. Известные упрощения

- Клосс + `boost·s³` — приближение; реальная характеристика может иметь другой «горб».
- Ток — по балансу мощности, не по полной схеме замещения.
- Тепловая модель — однотельная.
- Кабель — по справочным таблицам.
- Защита — по номиналам и грубой селективности.
- ПЧ — скалярный, без PWM.
- Y–Δ/AT — идеальное переключение.
- Однофазные — типовые кривые, без отдельной схемы вспомогательной обмотки.

Если меняете формулы — обновите этот файл, `docs/LIMITATIONS.md`, эталоны в `docs/TESTING.md` и запустите `npm test`.


## Тепловая модель: горячий/холодный пуск

Температура обмотки:

`T(t) = Tуст − (Tуст − T0)·exp(−t/τ)`

`T0` — начальная температура (окружающая для холодного, `Tокр + (Tпред−Tокр)·hotPct/100` для горячего). Время до предела:

`t = −τ·ln((Tуст − Tпред)/(Tуст − T0))`

Класс перегрузки 10/20/30 масштабирует время (класс 20 — вдвое, 30 — втрое). Пуски в час и постоянная охлаждения — справочные/для оценки теплового запаса; модель однотельная.
