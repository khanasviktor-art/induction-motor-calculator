# Справочные данные

Все данные — в `src/data.js`, кроме однофазных типовых кривых (`TYPICAL_1PH` в `src/engine.js`).

> Это **справочные** данные для инженерной оценки. Они не являются выпиской из каталога производителя или нормативного документа. Для проектирования проверяйте по первоисточнику.

## 1. Двигатели АИР

`MOTOR_DB` — 54 записи. Исходный формат — массив:

```
[тип, P2 кВт, полюса, n об/мин, Uн, I при 380 В, КПД %, cosφ,
 Mmax/Mн, Mп/Mн, Iп/Iн, typical?]
```

После преобразования:

```js
{
  type: 'АИР160S4',
  p2: 15,
  poles: 4,
  n: 1460,
  un: '380/660',
  i380: 29.0,
  eff: 89.0,
  cos: 0.87,
  mmax: 2.3,
  mst: 2.2,
  kst: 7.0,
  typical: false
}
```

Правила:

- `p2` — кВт.
- `poles` — 2/4/6/8.
- `n` — при 50 Гц; при 60 Гц пересчитывается.
- `typical: true` — типовые, а не паспортные; крупные 45…315 кВт.
- Для 2/6/8 полюсов должно быть достаточно точек в группе для интерполяции; иначе используется группа 4 полюсов с поправкой.
- `TYPICAL_BIG` — опорные точки для экстраполяции крупных машин.

### Как добавить

1. Добавьте строку в `MOTOR_RAW` (сохраняя порядок по мощности).
2. Если данных нет — `typical: true`.
3. Проверьте `selectMotor`, `typical`, `buildMotor` на новом типе.
4. Добавьте сценарий в тесты.
5. Обновите этот файл.

## 2. Однофазные типовые данные

`TYPICAL_1PH` в `src/engine.js`:

```js
{
  capacitor: { p2: [...], eff: [...], cos: [...], kst: [...], mst: [...], mmax: [...], slip: [...] },
  split:     { ... },
  psc:       { ... }
}
```

- `capacitor` — конденсаторный (пуск/работа).
- `split` — с расщеплённой фазой.
- `psc` — постоянный конденсатор.
- `p2` — до 7,5 кВт (данные 5,5/7,5 добавлены). Выше 7,5 кВт берётся последняя точка и выдаётся предупреждение: это редкий специальный случай, не типовой ряд.
- Число обмоток не задаётся: у однофазного главная + пусковая; полюса — это скорость, а не обмотки.
- `slip` — в процентах.
- Интерполяция логарифмическая; на краях — крайние значения.
- Конденсатор **не подбирается**.

## 3. Кабели

В `MC.data`:

```js
SECTIONS        // ряд сечений, мм²
AMPACITY        // базовые допустимые токи по материалу/изоляции
TEMP_FACTOR     // поправка на температуру
GROUP_FACTOR    // поправка на группировку
LAYING          // способы прокладки
INSULATION      // ПВХ/XLPE
RHO             // удельное сопротивление
TEMP_COEF       // температурный коэффициент
X_CABLE         // 0,00008 Ом/м (0,08 Ом/км)
```

- `AMPACITY` — базовый ток для 3 нагруженных жил, воздуха, 25/30 °C.
- Поправки в расчёте: температура, группировка, способ прокладки, изоляция, число нагруженных жил, параллельные кабели.
- Для 1 фазы — 2 нагруженные жилы; для 3 фаз — 3.
- `R = ρ·L/S`; `ΔU` — по формулам из `docs/MODEL.md`.

## 4. Аппараты

В `MC.data`:

- `BREAKERS` — MCB/MCCB (номиналы, кривые, `Icu`).
- `CURVE_MAG` — кратности отсечки для B/C/D.
- `CONTACTORS` — `{ i, kw }` (AC-3).
- `THERMAL_RELAYS` — диапазоны.
- `FUSES_AM` — номиналы aM.

Это упрощённые таблицы; селективность — по отношению номиналов, не по кривым.

## 5. Источники и качество

- Каталожные АИР — типовые справочные данные серии.
- Крупные — типовые, помечены.
- Кабели — справочные таблицы ПУЭ/IEC (не полная выписка).
- Аппараты — типовые ряды, не конкретный производитель.

Правила:

- Не выдавайте типовые данные за паспорт.
- При добавлении указывайте `typical: true`, если это оценка.
- Не смешивайте 50/60 Гц: `n` пересчитывается, но данные — для 50 Гц.
- Проверяйте, что единицы совпадают (кВт, А, Н·м, мм², °C).
- Не добавляйте данные без возможности проверить (лучше `typical`).

## 6. Схема данных в отчёте

`buildReport` возвращает:

```js
{
  motor, cable, breaker, relay, contactor, fuse, rcd,
  op, sweep, drop, dropStart, checks, iStart, ...
}
```

- `motor` — модель (P₂, P₁, I, n, моменты, J, температуры).
- `cable` — сечение, PE, параллельность, `loaded`, поправки.
- `breaker` — тип, `In`, кривая/уставка, `poles`.
- `op` — рабочая точка.
- `sweep` — 151 точка для графиков.
- `checks` — проверки.

## 7. Лицензия данных

Данные собраны из открытых справочных источников и типовых таблиц. Если вы добавляете данные из конкретного каталога, убедитесь, что у вас есть право на их распространение, и укажите источник в этом файле.
