# План развития

Статус: **0.13.1** · обновлено 2026-11-10.

Это рабочий план, а не обещание дат. Порядок этапов выбран по приоритету:
сначала дешёвые улучшения и фундамент, затем функции, которым нужны данные.

## Принципы

- Один собранный `index.html`, без runtime-зависимостей и CDN.
- Публичный API `MC.engine` / `MC.thermal` не ломаем без необходимости.
- Чистые расчёты — в модулях без DOM; интерфейс — в `app.js`.
- Новые данные — только с источником. Без источника — явная оценка, а не «паспорт».
- Числа не меняем «по пути»: сначала golden-тесты, потом рефакторинг.
- Unit-тесты для формул, Playwright — для UI, отчёта, XLSX и i18n.
- macOS — только Apple Silicon (`arm64`).
- Каждый релиз: версия, changelog, тесты, arm64 DMG, GitHub Release, CI/Pages.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Приоритет | 5+7 → 6 → 4 → 3 → 2 → 1 |
| Однофазные | Искать публичные данные; отдельные модели |
| Конденсатор | Подбор + проверка напряжения/тока |
| База | 4А/4АМ, 5А/5АМ/5АИ, АИС/AIS |
| Источники базы | Публичные каталоги с указанием источников |
| Селективность | 2–3 аппарата, стандартные IEC-кривые, экран + PDF |
| Excel | «Исходные данные» + формулы I/P₁/M/ΔU; кабель/автомат — значения |
| Экспорт | PNG + PDF, только выбранные графики |
| Рефакторинг | Постепенно, один HTML и API |
| Предупреждения | Линия > 200 м, J > 10× ротора, U ±10 %, пуск > 25 с/не завершён, перегрев, Icu |

## 0.13.1 — селективность

Цель: увидеть, как согласуются 2–3 аппарата в цепочке.

- До 3 аппаратов на одном лог-лог графике.
- Стандартные IEC-кривые из `src/vtc.js`; точные заводские кривые — позже.
- Проверка отношения отсечек и тепловых зон.
- Таблица «аппарат — номинал — отсечка — вывод».
- Экран и PDF; выбор графиков из 0.12.0 сохраняется.
- Тесты: 2 и 3 аппарата, отсутствие ложной селективности, PDF.

Ограничение: стандартные кривые дают ориентировочную селективность;
для точной нужны оцифрованные кривые производителя.

## 0.14.0 — база двигателей

Цель: не только АИР.

- 4А / 4АМ.
- 5А / 5АМ / 5АИ.
- АИС / AIS.
- Поля: тип, `P₂`, полюса, `U`, `f`, `η`, `cosφ`, `Iн`, `Iп/Iн`, `Mп/Mн`, `Mmax/Mн`, `n`, `J`, источник.
- Источник и дата — в `docs/DATA.md` и в записи каталога.
- UI: фильтры по серии/полюсам/мощности; существующий расчёт не ломается.
- Тесты: выборка по каждой серии, границы, i18n.

NEMA 60 Гц и IEC IE2/IE3/IE4 — отдельный этап после 4А/5А/АИС,
чтобы не смешивать разные системы данных.

## 0.15.0 — однофазные двигатели

Цель: уйти от «оценки по типовым» к отдельным моделям.

- Capacitor-start.
- Capacitor-start/run.
- PSC.
- Split-phase.
- Главная и пусковая обмотки, пусковой и рабочий конденсатор,
  центробежный выключатель — в модели.
- Подбор конденсатора + проверка напряжения/тока + ручной override.
- Публичные данные; где данных нет — параметризованная модель
  с явными допущениями, а не «заводская точность».
- Тесты: пусковой ток/момент, ёмкость, напряжение на конденсаторе,
  переключение пусковой обмотки.

## Бэклог

Не входит в ближайшие три релиза:

- NEMA 60 Гц, 230/460 В, frame data.
- IEC IE2/IE3/IE4 по конкретным брендам.
- Точные заводские кривые для селективности.
- Экспорт выбранных графиков в ZIP.
- Windows-exe 0.13+ (собирается отдельно).
- Расширение однофазной базы после первых моделей.
