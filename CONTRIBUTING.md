# Участие в разработке

Спасибо, что хотите помочь. Проект маленький, но инженерный: важны воспроизводимость и честные ограничения.

## 1. Перед началом

- Прочитайте `README.md`, `docs/ARCHITECTURE.md`, `docs/MODEL.md`, `docs/LIMITATIONS.md`.
- Проверьте, нет ли уже issue/PR по теме.
- Для крупных изменений сначала откройте issue с предложением.

## 2. Что можно улучшать

- Новые двигатели и уточнение данных.
- Новые серии аппаратов/кабелей.
- Улучшение модели (с тестами и документацией).
- Новые способы пуска.
- Графики, доступность, мобильный вид.
- Тесты, документация, переводы.
- Исправление ошибок.

## 3. Процесс

1. Форкните репозиторий, создайте ветку:
   ```bash
   git checkout -b fix/short-description
   ```
2. Внесите изменения **в `src/`**, не в `index.html`.
3. Соберите:
   ```bash
   npm run build
   ```
4. Прогоните тесты:
   ```bash
   npm test
   ```
5. Обновите:
   - `docs/MODEL.md` — если формулы/допущения;
   - `docs/LIMITATIONS.md` — если появилось ограничение;
   - `docs/TESTING.md` — если эталоны;
   - `docs/DATA.md` — если данные;
   - `docs/screenshots/` — если UI;
   - `CHANGELOG.md`.
6. Закоммитьте `src/`, `index.html`, docs и tests.
7. Откройте PR по шаблону.

## 4. Стиль

- ES2020, IIFE, без модулей в рантайме.
- 2 пробела, LF, UTF-8.
- Идентификаторы — английские; UI/комментарии — русские.
- Никаких CDN, внешних шрифтов, runtime-зависимостей.
- Не редактируйте `index.html`.
- Не удаляйте кредит и предупреждения.

## 5. Тесты

- Новый двигатель/сценарий — добавьте в `tests/charts-static.mjs`.
- Новый способ пуска — в `tests/charts-transient.mjs`.
- Новая функция UI — в `tests/features.mjs`.
- Тест должен падать до исправления и проходить после.
- Скриншоты — в `test-results/` (не коммитить).

## 6. Commit messages

Рекомендуется Conventional Commits:

```
feat: add soft starter current limit
fix: use terminal voltage for cosphi
docs: describe single-phase limitations
test: cover 315 kW chart
```

Коротко, в повелительном наклонении, без «update».

## 7. Лицензия

Отправляя PR, вы соглашаетесь, что ваш вклад распространяется под MIT (см. `LICENSE`).

## 8. Чего не делать

- Не добавлять тяжёлые фреймворки.
- Не менять физику без тестов/документации.
- Не выдавать типовые данные за паспортные.
- Не удалять `?debug=1` (на нём тесты).
- Не коммитить `node_modules`, `test-results`, `.DS_Store`.
- Не менять кредит без согласования.
